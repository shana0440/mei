# Memory

Long-term memory is the files in `memory/`:

- `MEMORY.md` is the index: one line per note and task file, saying what the file holds.
- Notes: what you learn about the user, especially their corrections. One file per topic.
- Tasks: the progress of unfinished tasks, covering what is done and what is left, with the details a new session needs to continue. One file per task; delete it when the task is done.

Save what can't be looked up again. For what lives elsewhere, save a pointer: a line saying what it is and where to find it.

Start every note and task file with the date and time it was created and last updated, right under the title.

After a change, make `MEMORY.md` match the files that exist.
