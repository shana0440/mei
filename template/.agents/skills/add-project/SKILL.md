# Add project

1. Look at the location to understand its purpose. Ask the user if it is unclear.
2. Add an entry to `PROJECTS.md`, following its template:

   ```markdown
   ## <name>
   - Path: <path>
   - Purpose: <purpose>
   ```

3. Show the entry to the user.

Write the purpose in one short sentence:

- Say what the location is for.
- Keep only the purpose; leave details to the location itself.
